# 🐔 길건너기

**한 칸씩 뛰어서 차와 기차를 피하고, 통나무를 타고 강을 건너라!**

### [▶ 지금 플레이하기](http://ddanjit.duckdns.org/crossy/)

</div>

---

## 이런 게임이에요

닭을 한 칸씩 앞으로 뛰게 해서 끝없이 이어지는 길을 건너는 3D 아케이드예요.
도로의 차, 철길의 기차를 피하고, 강은 떠내려가는 통나무나 연잎을 밟고 건너요. 얼마나 멀리 갔는지가 점수예요.

- 🐔 혼자 하는 **무한 아케이드**, 멀리 갈수록 차와 강이 빨라져요
- 🦅 가만히 있거나 **뒤로 세 칸** 가면 독수리가 잡아가요
- 🪙 길에 떨어진 **동전**을 모아요 (이 브라우저에 쌓여요)
- 📱 **PC·모바일** 모두

## 조작

| 입력 | 하는 일 |
|:-:|---|
| ↑ ↓ ← → / W A S D | 그 방향으로 한 칸 뛰기 |
| 스페이스 | 앞으로 한 칸 (시작·다시 하기) |
| 탭 (모바일) | 앞으로 한 칸 |
| 밀기 (모바일) | 민 방향으로 한 칸 |

## 길

| 줄 | 설명 |
|---|---|
| 풀밭 | 안전해요. 나무와 바위는 지나갈 수 없어요 |
| 도로 | 차와 트럭이 줄마다 다른 속도·방향으로 달려요. 닿으면 끝 |
| 철길 | 철길이 빨갛게 깜빡이고 "🚂 기차!"가 뜨면 1.5초 안에 기차가 아주 빠르게 지나가요 |
| 강 | 물에 빠지면 끝. 통나무는 떠내려가니 타고 있다가 화면 밖으로 나가지 않게, 연잎은 가만히 있어요 |

## 끝나는 경우

- 차·기차에 치임
- 물에 빠짐, 통나무 타고 화면 밖으로 떠내려감
- 독수리: 가만히 10초쯤 있거나, 가장 멀리 간 곳에서 뒤로 세 칸

## 점수

**가장 멀리 간 줄 수.** 최고 기록과 모은 동전은 이 브라우저에 저장돼요.

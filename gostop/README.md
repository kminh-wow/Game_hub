## 이런 게임이에요

화투 48장으로 하는 고스톱이에요. **맞고(2명, 7점)**와 **고스톱(3명, 3점)**을 고를 수 있고, 사람이 모자라면 AI가 자리를 채워요. 혼자 들어가도 바로 할 수 있어요.
정한 판 수(기본 10판)가 끝나거나 누가 칩이 떨어지면 칩 순위로 끝나요. 게임 칩만 써요.

- 🌸 손패 1장을 내고 더미 1장을 뒤집어 **같은 월**을 먹어요
- 💥 **쪽 · 뻑 · 따닥 · 쓸 · 뻑 먹기 · 폭탄 · 흔들기 · 총통**이 모두 들어 있어요. 일어나면 화면에 크게 떠요
- 🙋 점수가 나면 **고 / 스톱**을 골라요
- 🧾 판이 끝나면 점수 내역, 고·흔들기·폭탄·나가리 배수, **피박·광박·멍박·고박**, 주고받은 칩을 결과 창으로 보여 줘요
- 🃏 화투 그림은 이미지 없이 코드로 그렸어요
- 👀 관전 가능, 나간 사람 자리는 AI가 이어서 해요, 📱 PC·모바일

## 하는 법

- **카드 내기:** 내 차례에 손패를 눌러요. 바닥에 같은 월이 있는 카드는 노란 테두리예요.
- **두 장 중 고르기:** 바닥에 같은 월이 두 장이면 먹을 카드를 골라요.
- **흔들기·폭탄:** 같은 월 세 장을 들고 있으면 물어봐요. 바닥에 그 월이 없으면 흔들기(×2), 한 장 있으면 폭탄(4장 먹고 피 뺏기, ×2, 그 뒤 두 번은 뒤집기만).
- **고·스톱:** 점수가 나면 고(계속)나 스톱(정산)을 골라요.
- 시간이 지나면 AI가 대신 둬요.

## 점수

| | |
|---|---|
| 광 | 3장 3점 (비광 끼면 2점) · 4장 4점 · 5장 15점 |
| 열끗 | 5장 1점, 1장마다 +1 · 고도리(2·4·8월 새) 5점 |
| 띠 | 5장 1점, 1장마다 +1 · 홍단·청단·초단 각 3점 |
| 피 | 10장 1점, 1장마다 +1 · 쌍피는 2장 · 국진(9월 열끗)은 열끗·쌍피 중 유리하게 |
| 고 | 1고 +1 · 2고 +2 · 3고부터 두 배씩 |
| 배수 | 흔들기·폭탄 ×2 · 나가리 다음 판 ×2 |
| 박 | 피박(피 5장 이하) · 광박(광 0장) · 멍박(열끗 0장, 이긴 사람 열끗 7장 이상) 각 ×2 |
| 고박 | 고 했다가 다른 사람이 나면, 고 한 사람이 다 냄 (맞고는 ×2) |
| 총통 | 처음 손패에 같은 월 네 장이면 바로 10점 |
| 피 뺏기 | 쪽 · 따닥 · 쓸 · 뻑 먹기 · 폭탄: 다른 사람 모두에게서 피 1장 |

정산 = 점수 × 배수 × 박 × 점당 칩 (진 사람마다)

## 방 설정

| 설정 | 기본 | 범위 |
|---|:-:|:-:|
| 방식 | 고스톱(3명) | 맞고(2명) / 고스톱(3명) |
| 시작 칩 | 10,000 | 1,000 ~ 100,000 |
| 점당 칩 | 100 | 10 ~ 1,000 |
| 판 수 | 10 | 0(칩이 떨어질 때까지) ~ 50 |
| 한 번 내는 시간 | 25초 | 10 ~ 60초 |

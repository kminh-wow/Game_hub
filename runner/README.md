**숫자 문을 골라 병사를 불리고, 끝없이 몰려오는 적을 막아라!**

## 이런 게임이에요

내 병사 무리가 도로를 달리고, 앞에서는 적이 끝없이 몰려와요.
**4칸 도로**를 좌우로 옮겨 다니며 칸마다 하나씩 있는 **숫자 문**을 고르고, **무기 상자**와 **철창 속 포로**, **동료**로 무리를 키워 최대한 멀리 가세요.

- 🏃 혼자 하는 **무한 러너**, 오래 갈수록 적이 많아지고 세져요
- 👣 큰 무리 사이사이에도 **작은 적 무리가 쉬지 않고** 와요
- 🔫 사격은 **자동**, 나는 좌우 이동만
- 📱 **PC·모바일** 모두 (화면을 끌어서 이동)
- 🏆 최고 기록은 이 브라우저에 저장돼요

## 조작

| 입력 | 하는 일 |
|:-:|---|
| ← → / A D | 한 칸씩 이동 (누르고 있으면 계속) |
| 화면 끌기 (마우스·터치) | 끈 위치로 이동 |
| P / Esc | 일시정지 |
| Enter / Space | 시작, 다시 하기 |

## 숫자 문

칸마다 문이 하나씩, 4개가 한 줄로 와요. **무리 가운데가 있는 칸**의 문 하나만 적용돼요.
보통 좋은 문 1~2개, 나쁜 문 2~3개가 섞여 있고, 가끔 동료 문이 끼어 있어요.

| 문 | 색 | 효과 |
|---|---|---|
| `+20` | 파랑 | 병사 +20 |
| `-15` | 빨강 | 병사 -15 |
| `×2` `×3` | 파랑 | 병사 2배, 3배 |
| `÷2` `÷3` | 빨강 | 병사 반, 3분의 1 |
| `?` | 보라 | 지나가 봐야 아는 숫자 |
| 동료 이름 | 초록 | 동료 합류 |

- **문을 쏘면 숫자가 올라가요.** `-15` 문도 계속 쏘면 `+`가 돼요. 대신 그동안 적은 덜 맞아요.
- 병사 수에는 제한이 없어요. 대신 1000명이 넘으면 곱하기 문이 드물게, 1만 명이 넘으면 안 나와요.

## 무기 (상자를 쏴서 부수면 얻어요)

| 무기 | 특징 |
|---|---|
| 권총 | 처음 무기, 무난함 |
| 기관총 | 빠른 연사 |
| 샷건 | 부채꼴 산탄, 가까이 강함 |
| 저격총 | 멀리, 여러 명 관통 |
| 로켓 | 범위 폭발 |
| 화염방사기 | 아주 짧고 강함, 관통 |

- 지금과 **같은 무기** 상자를 부수면 **레벨 업** (최대 5), 다른 무기면 그 무기로 바뀌어요.
- 아이템 상자: 💥 수류탄(앞쪽 적을 크게 날림), 🛡 보호막(5초 동안 병사를 안 잃음), 🐢 느리게(6초 동안 적이 느려짐)

## 동료 (초록 문)

| 동료 | 하는 일 |
|---|---|
| 방패병 | 맞붙을 때 잃는 병사를 절반 대신 막아줌 (체력이 다하면 떠남) |
| 의무병 | 2초마다 병사 회복 |
| 포병 | 3초마다 가장 큰 적 무리에 포격 |

다시 얻으면 레벨이 올라요.

## 적

| 적 | 특징 |
|---|---|
| 졸병 (빨강) | 떼로 몰려옴 |
| 돌격병 (주황) | 빠름, 닿으면 2명씩 쓰러뜨림 |
| 방패병 (회색) | 정면 총알에 강함 (저격총·로켓·화염방사기로) |
| 거인 | 크고 단단함, 닿으면 10명씩 쓰러뜨림 |
| 보스 | 1000m마다 등장. 폭탄(빨간 원을 피하세요), 부하 소환, 돌진 |

- 적 무리에 닿으면 서로 숫자가 줄어요. **병사가 0명이 되면 끝.**
- 옆으로 비켜서 **놓친 적은 1명당 병사 1명**을 잃어요("놓침 -N"). 거인(10명)이나 돌격병(2명)과 맞붙는 것보다는 덜 아파요.
- 보스를 쓰러뜨리면 점수 +500, 병사 +20, 무기 레벨 업.

## 점수

**달린 거리(m) + 보스 보너스.** 처치 수는 따로 보여줘요.

## 이런 게임이에요

엄폐물이 흩어진 3D 아레나에서 **1인칭 시점**으로 싸우는 턴제 슈팅 게임이에요.
돌아가며 한 명씩 차례가 오고, 내 차례에는 **움직이고 → 조준하고 → 쏘면**(소총 3발, 저격총·수류탄 1발) 끝나요. 마지막까지 살아남은 사람이 이겨요.
판이 길어지면 **안전 구역**이 줄어들어 숨어만 있을 수는 없어요.

- 👫 **2~4명** 대전, 혼자라면 **허수아비**(연습)나 **AI(하·중·상)**와 대결
- 🧱 판마다 새로 깔리는 **엄폐물** (상자, 낮은 벽, 긴 벽, 기둥)
- 👀 벽 뒤는 안 보여요. 숨고, 찾고, 노리세요
- 📦 맵 곳곳의 **보급 상자**(탄약·구급)를 주우세요
- 🔴 6라운드부터 **안전 구역**이 줄어들어요
- 💻 마우스와 키보드가 필요해서 **PC 전용**이에요
- 👀 **관전**: 게임 중인 방도 들어가서 구경할 수 있어요

## 조작

| 입력 | 하는 일 |
|:-:|---|
| 화면 클릭 | 마우스 잠금 (둘러보기 시작) · Esc 로 풀기 |
| 마우스 | 둘러보기 (내 차례가 아니어도 둘러볼 수 있어요) |
| 조준선 | 네 막대 사이 간격이 탄이 퍼지는 범위, 상대를 겨누면 빨갛게 바뀌고 이름·거리가 떠요. 수류탄은 날아갈 궤적과 터지는 범위가 보여요 |
| W A S D | 이동 (차례마다 7m 까지, 바닥의 초록 원이 갈 수 있는 범위) |
| C | 앉기 / 일어서기 (낮은 엄폐물 뒤에 숨기, 탄이 덜 퍼짐, 대신 걸으면 이동 거리를 1.5배 씀) |
| 1 / 2 / 3 | 소총 / 저격총 / 수류탄 |
| 좌클릭 | 발사 (소총은 한 차례 3발, 저격총·수류탄은 1발) |
| E | 차례 끝내기 (덜 쏘고 넘길 때) |
| 우클릭 (누르고 있기) | 조준 확대 (저격총은 스코프) |

## 무기

| 무기 | 맞히는 법 | 피해 | 한 차례에 | 판마다 탄약 |
|---|---|---|:-:|:-:|
| 소총 | 바로 날아감, 조금 퍼짐 | 몸 25 · 머리 50 (멀면 줄어듦) | 3발 | 45발 |
| 저격총 | 바로 날아감, 거의 안 퍼짐 | 몸 70 · 머리 100 | 1발 | 3발 |
| 수류탄 | 포물선으로 던짐, 닿으면 폭발 | 가까울수록 최대 70 (벽 뒤면 줄어듦) | 1개 | 2개 |

- 한 차례에는 **한 가지 무기만** 써요. 소총은 3발까지 쏠 수 있고, 발사 사이에 다시 조준하거나 조금 움직여도 돼요.
- 정해진 수만큼 쏘면 차례가 끝나요. 덜 쏘고 넘기려면 **E(차례 끝내기)**.

## 규칙

| 항목 | 내용 |
|---|---|
| 체력 | 모두 100 |
| 차례 | 들어온 순서대로 돌아가며, 첫 차례는 무작위 |
| 시간 | 한 차례 제한 시간(기본 25초) 안에 안 쏘면 차례가 넘어가요 |
| 이동 | 차례마다 7m. 엄폐물과 다른 사람은 통과할 수 없어요 |
| 피해 | 내 수류탄에 나도 다쳐요 |
| 나가기 | 게임 도중 나가면 탈락 |
| 라운드 | 모두 한 번씩 차례를 마치면 한 라운드 |
| 보급 상자 | 처음 4개, 라운드마다 1개씩 늘어요(최대 6개). 위로 지나가면 주워요. 탄약 상자는 소총 +15·저격총 +1·수류탄 +1, 구급상자는 체력 +35 (처음 양까지만) |
| 안전 구역 | 6라운드부터 8라운드에 걸쳐 0까지 줄어요. 새 라운드가 시작될 때 구역 밖에 있으면 10, 20, 30…씩 커지는 피해. 붉은 벽이 지금 구역, 바닥 흰 원이 다음 라운드 구역 |
| 승리 | 마지막까지 살아남은 한 명 (모두 쓰러지면 무승부) |

## 팁

- 🧱 쏘고 나면 상대 차례예요. **쏘기 전에 엄폐물 옆으로** 움직여 두세요.
- 🎯 머리는 피해가 두 배예요. 저격총 헤드샷이면 한 방!
- 💣 벽 뒤에 숨은 상대에겐 **수류탄**을 높이 던져 넘기세요.
- 🧎 차례를 끝내기 전에 **앉아 두면** 낮은 상자 뒤에 몸이 숨어요.
- ⚪ 차례를 끝낼 때는 **흰 원 안**에 있어야 다음 라운드에 안 다쳐요.

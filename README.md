## 이렇게 시작하세요

1. **[Ddan Jit](http://ddanjit.duckdns.org)에 접속**해서 하고 싶은 게임을 고릅니다.
2. **메인 화면에서 닉네임을 정합니다.** 한 번만 정하면 모든 게임에 그 이름으로 바로 들어가요. 가입도 로그인도 필요 없어요.
3. **친구에게 주소를 보내세요.** 같은 방에 들어오면 바로 시작입니다.

크롬, 엣지, 사파리 같은 최신 브라우저에서 동작합니다. 앱을 설치할 필요는 없어요.

## 자주 묻는 질문

<details>
<summary><b>회원가입을 해야 하나요?</b></summary>

아니요. 메인 화면에서 닉네임만 한 번 정하면 모든 게임에 바로 들어갈 수 있어요. 닉네임은 이 브라우저에만 저장되고, 메인 화면의 **닉네임 바꾸기**로 언제든 바꿀 수 있어요.
</details>

<details>
<summary><b>점수나 전적이 저장되나요?</b></summary>

**길건너기·사과게임·박스헤드(혼자 하기)·숫자러너·팩맨**은 점수가 서버 순위표에 올라가요. 메인 화면 아래 **🏆 순위**와 각 게임 결과 창에서 이번 주·전체 상위 10명을 볼 수 있어요(허브 닉네임으로 올라가고, 이번 주 순위는 매주 월요일 0시에 새로 시작). 그 밖의 전적은 아직 저장하지 않아요. 탁구 난이도별 전적과 길건너기 동전은 내 브라우저에만 저장돼요.
서버를 점검하면 진행 중인 방도 초기화돼요.
</details>

<details>
<summary><b>순위에 "이 닉네임은 다른 브라우저에서 쓰고 있어요"라고 나와요</b></summary>

순위표 닉네임은 **처음 점수를 올린 브라우저의 것**이 돼요. 남이 내 이름으로 기록을 올리지 못하게 하려는 거예요.
다른 컴퓨터·폰이나 브라우저 데이터를 지운 뒤에는 같은 닉네임을 다시 못 써요. 그럴 땐 다른 닉네임을 쓰거나 운영자에게 풀어 달라고 말해 주세요.
(점수는 판을 시작할 때 서버가 받아 둔 시간으로 검사해요. 오래 켜 둔 화면에서 "새로고침하고 다시 해 주세요"가 나오면 새로고침하면 돼요.)
</details>

<details>
<summary><b>"이미 접속 중인 닉네임"이라고 떠요.</b></summary>

같은 닉네임을 다른 사람이 쓰고 있거나, 다른 기기에서 접속한 연결이 아직 남아 있는 경우예요.

- **같은 브라우저**라면 다시 입장할 때 예전 연결을 자동으로 이어받아요.
- **다른 기기**에서 쓰던 닉네임이라면 1분 정도 뒤에 다시 시도해 주세요.
</details>

<details>
<summary><b>화면이 이상하거나 예전 모습 그대로예요.</b></summary>

업데이트 직후라면 브라우저가 예전 화면을 기억하고 있을 수 있어요.
<kbd>Ctrl</kbd> + <kbd>F5</kbd>(맥은 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>R</kbd>)로 새로고침해 주세요.
</details>

<details>
<summary><b>끝말잇기에서 욕도 인정되나요?</b></summary>

표준국어대사전이나 끄투 단어에 **실려 있는 말이면 인정**돼요. 사전에 없는 비속어는 인정하지 않아요.
모르는 사람과 할 때는 매너를 지켜 주세요.
</details>

<details>
<summary><b>게임 중인 방도 구경할 수 있나요?</b></summary>

네, 끝말잇기·행맨·오목·요트 다이스·포트리스·턴제 FPS는 로비에서 **"게임 중 · 관전하기"**가 붙은 방(또는 꽉 찬 방)을 누르면 구경할 수 있어요. 구경하는 동안 말하는 건 되지만(채팅에 "관전" 표시가 붙어요), 게임에는 끼어들 수 없어요. 쿼리도는 메뉴의 **"코드로 관전"**에 방 코드를 넣으면 돼요. 팩맨, 숫자러너, 탁구, 길건너기, 사과게임, 박스헤드 혼자 하기는 혼자 하는 게임이라 구경할 게 없어요.
</details>

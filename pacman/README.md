## 이런 게임이에요

미로 곳곳에 흩어진 **점 244개**를 모두 먹으면 다음 레벨로 넘어갑니다.
유령 네 마리가 저마다의 방식으로 쫓아오니 잡히지 않게 조심하세요.
구석의 커다란 **파워 점**을 먹으면 잠깐 동안 유령이 파랗게 질려서, 거꾸로 잡아먹을 수 있어요.

- 🕹️ 설치 없이 브라우저에서 바로 하는 **1인용 아케이드**
- 👻 성격이 다른 유령 네 마리
- 📈 레벨이 오를수록 빨라지고, 유령이 겁먹는 시간은 짧아져요.
- 🎚️ **난이도 4단계**: 쉬움 · 보통 · 중상 · 어려움

## 조작법

| 동작 | 키 |
|---|---|
| 이동 | 방향키 또는 <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd> |
| 시작 / 다시 시작 | <kbd>Enter</kbd> 또는 <kbd>Space</kbd> |
| 일시정지 | <kbd>P</kbd> |
| 난이도 고르기 (시작 전·게임 오버 때) | 버튼 또는 <kbd>1</kbd>~<kbd>4</kbd> |
| 모바일 | 화면을 쓸어서 이동, 탭해서 시작 |

갈림길에 닿기 전에 미리 방향키를 눌러 두면, 그 갈림길에서 알아서 꺾어요.

## 난이도

| | 쉬움 | 보통 | 중상 (기본) | 어려움 |
|---|:-:|:-:|:-:|:-:|
| 유령 속도 | 느림 | 조금 느림 | 보통 | 빠름 |
| 유령이 겁먹는 시간 (1레벨) | 10초 | 8초 | 6초 | 4초 |
| 목숨 | 5 | 4 | 3 | 3 |
| 유령이 가끔 엉뚱한 길로 감 | 자주 | 가끔 | 없음 | 없음 |
| 유령이 쉬는 시간 (흩어지기) | 김 | 조금 김 | 보통 | 짧음 |
| 유령이 집에서 나오는 시점 | 늦게 | 조금 늦게 | 보통 | 빨리 |

고른 난이도는 기억해 두고, **최고 점수는 난이도별로** 따로 저장돼요.

## 점수

| 먹은 것 | 점수 |
|---|---:|
| 점 | 10 |
| 파워 점 | 50 |
| 유령 (파워 점 하나로 연속해서) | 200 → 400 → 800 → 1600 |

- 목숨은 난이도에 따라 **3~5개**로 시작하고, **10,000점**을 넘으면 하나 더 생겨요.
- **최고 점수**는 난이도별로 브라우저에 저장돼요.

## 유령을 알아 두세요

| 유령 | 색 | 쫓는 방식 |
|---|---|---|
| **블링키** | 🔴 빨강 | 팩맨을 곧장 쫓아와요. |
| **핑키** | 🩷 분홍 | 팩맨이 가는 방향으로 **4칸 앞**을 노려요. |
| **잉키** | 🩵 하늘 | 블링키와 협공해요. 팩맨 앞을 기준으로 블링키의 반대편을 노려요. |
| **클라이드** | 🟠 주황 | 멀리 있으면 쫓아오다가, 가까워지면 딴청을 피우며 구석으로 가요. |

유령들은 **쫓기**와 **흩어지기**를 번갈아 해요. 흩어질 때는 각자 자기 구석으로 돌아가니, 그때가 점을 먹을 기회예요.

## 팁

- 🚇 **양옆 터널**을 이용하세요. 유령은 터널 안에서 느려져요.
- 💊 **파워 점은 아껴 두세요.** 유령이 몰려올 때 먹어야 한꺼번에 잡을 수 있어요.
- ⏱️ 파랗게 질린 유령이 **하얗게 깜빡이면** 곧 원래대로 돌아와요.

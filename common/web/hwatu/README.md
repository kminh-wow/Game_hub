# 화투 그림 출처 · 라이선스

이 폴더의 카드 그림 48장(`월-번호.svg`)은 **Louie Mantia** 님이 그려 Wikimedia Commons에 올린 하나후다(花札) 그림입니다.

- 작가: [Louie Mantia](https://commons.wikimedia.org/wiki/User:Louiemantia)
- 라이선스: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
- 바꾼 것: 그림 내용은 그대로 두고 파일 이름만 화투 순서로 바꿨습니다. 화투는 11월이 오동, 12월이 비라서 하나후다의 12월(오동) 그림을 11월에, 11월(비) 그림을 12월에 씁니다. 화면에서 광(光)·쌍피·월 표시를 그 위에 덧그립니다(`../hwatu.js`).
- 이 폴더의 그림을 고쳐서 다시 배포하면 같은 CC BY-SA 4.0으로 공개해야 합니다. 저장소의 나머지 코드는 이 라이선스와 상관없습니다.

번호는 `gostop/app/rules.py`의 `KINDS` 순서(예: 1월 = 광, 홍단, 피, 피)를 따릅니다.

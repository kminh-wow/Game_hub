# Quoridor 3D 에셋

## 캐릭터 교체 (2026-09-26)

현재 `pawn.glb`는 팔다리·얼굴·장식 없는 둥근 머리와 넓어지는 몸통의 단색 보드게임 말이다. 1P 빨강, 2P 파랑이며 `PawnSolid_Red` 재질을 웹에서 플레이어별로 복제해 색상을 지정한다. 높이 0.8, 최대 몸통 지름 0.468, 머리 지름 0.35다. 기존 리그의 Root에 전체 메시를 연결하고 같은 이름의 6개 클립을 말의 기울임·탄성·작은 바운스 동작으로 교체했다. 원본은 `quoridor_assets.blend`, 이전 로봇 원본은 `quoridor_robot_archive.blend`에 보존했다. `Classic_Pawns` 장면에서 새 두 색상을 볼 수 있다. 이번 교체 후 플레이 테스트는 사용자 요청에 따라 실행하지 않았다. 아래 로봇 제작 기록과 export-validation.json은 최초 버전 기록이다.

2026-09-26, Blender MCP와 Blender 5.2에서 직접 제작한 첫 버전. 외부 모델·텍스처는 사용하지 않았다.

## 결과물

- `blender/quoridor_assets.blend`: 모델 원본, 공용 리그, 6개 애니메이션, 보드 미리보기 통합 파일.
- `../../web/assets/models/board_base.glb`: 보드 받침대.
- `../../web/assets/models/tile.glb`: 반복 배치할 칸.
- `../../web/assets/models/wall.glb`: 가로 벽. 세로 벽은 높이축 기준 90도 회전.
- `../../web/assets/models/pawn.glb`: 로봇 말, 스킨과 7개 본, 6개 애니메이션.
- `blender/export-validation.json`: GLB 파일 크기, 메시·스킨 개수, 클립 이름 검사 결과.

위 GLB 경로는 프로젝트 루트 기준으로는 `web/assets/models/`이다.

## Blender 파일 열기

기본으로 `Quoridor_Preview` 장면이 열린다. 보드 81칸, 예시 벽 3개, 청록·주황 로봇 말이 배치되어 있다. 타임라인을 재생하면 대기 동작을 확인할 수 있다.

`Quoridor_Assets` 장면에는 내보내기용 모델이 각각 원점에 있다. 겹쳐 보이는 것은 의도한 배치다. 편집할 모델만 선택해 로컬 보기로 확인한다. 기존 기본 `Scene`은 보존했다.

`Pawn_Rig`의 Action을 선택해 동작을 확인한다. NLA 트랙은 클립 보관용으로 음소거되어 있고, 기본 활성 Action은 `Idle`이다.

| 클립 | 길이 | 용도 |
|---|---:|---|
| Idle | 2초 | 반복 대기 |
| Walk | 0.6초 | 반복 걷기 |
| Jump | 0.7초 | 점프 자세 |
| PlaceWall | 0.7초 | 벽 설치 손짓 |
| Win | 1.6초 | 승리 |
| Lose | 1.4초 | 패배 |

제자리 애니메이션이다. 실제 칸 사이 이동, 점프 높이, 방향 전환은 게임 코드에서 적용한다. 각 클립의 시작과 끝은 기본 자세로 돌아간다. 제작 프레임레이트는 30fps다.

## 웹 연결 규격

- GLB는 Y-up이며 캐릭터 정면은 +Z다. Blender 원본 정면은 -Y다.
- 칸 중심 간격 1, 보드 중심은 원점이다.
- Blender 미리보기의 칸 바닥 높이는 0.35, 칸 윗면은 0.45다. 웹에서는 각각 Y 좌표에 적용한다.
- 캐릭터 발밑과 예시 벽 바닥은 높이 0.45에 배치했다.
- 칸 너비 0.8, 벽 길이 1.8, 벽 최대 두께 0.16, 캐릭터 높이는 약 0.745다.
- `pawn.glb`의 `PlayerColor` 재질을 복제해 플레이어별 색상을 변경한다. 미리보기의 주황색은 Blender 선형 RGB `(0.95, 0.24, 0.055)`다. 다른 플레이어의 재질까지 같이 바뀌지 않도록 재질을 복제한다.
- 스킨이 있는 캐릭터를 여러 개 만들 때는 Three.js `SkeletonUtils.clone` 등 스켈레톤 복제를 지원하는 방식으로 복제하고, 각각 AnimationMixer를 사용한다.
- 재내보내기 시 **선택한 오브젝트 + 활성 장면만** 내보낸다. 캐릭터는 `Pawn_Rig`와 `Pawn_Mesh`를 함께 선택하고 Actions 모드로 내보낸다.

## 확인 범위와 남은 작업

모델 외관·걷기 자세를 Blender 뷰포트에서 확인했다. GLB 4개의 메시 개수와 캐릭터의 스킨·6개 클립을 검사하고, 캐릭터 GLB를 Blender에 재수입해 리그와 클립 보존을 확인했다.

웹 게임의 3D 화면에 연결했고, 브라우저에서 모의 서버 메시지로 이동·점프·벽 설치·승패 전환을 검증했다. 실제 서버 대전과 성능 측정은 아직 하지 않았다. 테이블과 목표 장식은 선택 에셋이므로 이번 제작에 포함하지 않았다.

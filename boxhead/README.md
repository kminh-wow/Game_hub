## 이런 게임이에요

위에서 비스듬히 내려다보는 아레나에서 사방으로 몰려오는 좀비를 총으로 막는 서바이벌 슈팅이에요.
레벨을 깰 때마다 더 많고, 더 빠르고, 더 단단해져요. 좀비를 다 잡으면 **불덩이를 쏘는 악마**가 나와요.
일본 플래시 게임 시리즈 *Boxhead*(Sean Cooper)의 방식을 따랐어요. 그림은 하나도 가져오지 않고 코드로 직접 그렸어요.

- 🧟 **좀비**: 느리지만 떼로 몰려와요. 벽을 돌아서도 쫓아와요.
- 😈 **악마** (2레벨부터): 단단하고, 거리를 두고 돌며 불덩이를 쏴요. 잡으면 탄약 상자를 떨어뜨려요.
- 🔫 **무기**: 권총(탄약 무한) → 샷건(가까이서 세다) → 기관총(빠르다). 탄약 상자를 먹으면 하나씩 열려요.
- 🔥 **연속 킬 배율**: 3초 안에 계속 잡으면 점수 배율이 올라가요 (최대 ×30).
- ❤️ 가만히 있으면 체력이 천천히 차고, 레벨을 깨면 보급 상자로 체력과 탄약이 가득 차요.
- 🏆 혼자 하기는 **순위표**(이번 주·전체)에 올라가요.
- 👥 **같이 하기**: 2~4명 협동. 점수와 탄약 상자는 같이 쓰고, 쓰러져도 다음 레벨에 다시 일어나요. 모두 쓰러지면 끝이에요.
- 📱 **PC·모바일** 모두

## 조작

| 입력 | 하는 일 |
|:-:|---|
| W A S D / 방향키 | 8방향 이동 (W+A 처럼 같이 누르면 대각선, 마지막에 간 방향을 봐요) |
| 스페이스 · 마우스 클릭 · J | 보는 방향으로 발사 |
| Shift | 걷지 않고 방향만 바꾸기 (제자리에서 조준) |
| 1 · 2 · 3 / Q · E | 권총 · 샷건 · 기관총 바꾸기 |
| Esc · P | 멈춤 (혼자 하기) |
| 폰 | 왼쪽 조이스틱(8방향), 오른쪽 발사 · 방향 고정 · 무기 버튼 |

## 같이 하기는 이렇게 돌아가요

방장의 브라우저가 게임을 계산하고, 서버는 입력과 화면을 전달만 해요. 그래서 **방장이 나가면 그 판은 끝나요.**
방장 컴퓨터가 느리면 모두 느려질 수 있어요. 협동 점수는 순위표에 올리지 않아요.
